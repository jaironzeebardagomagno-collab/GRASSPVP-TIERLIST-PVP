GRASS Tier List V9

This version uses the exact GRASS kit icon artwork from the reference image:
DiaSMP, NethPOT, NethSMP, Sword, Axe, UHC, Crystal, Mace, SpearMace.

Files:
- index.html
- script.js
- style.css
- 9 kit PNG icons in the same folder as index.html

IMPORTANT:
Upload ALL files together to the same GitHub repository folder/root. No assets folder is needed.

The kit icons appear in:
1. Players page beside each assigned kit
2. Kit Tier List kit headers
3. Player kit rows in the tier list

To use public image URLs instead:
Editor Login -> Settings -> Kit Icons & Aura -> paste each image URL -> Save Settings.
If a URL is blank, the included PNG is used automatically.

The tier icon URL settings are separate from the kit icons.
